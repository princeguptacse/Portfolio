About the Project
This personal portfolio website serves as a central hub showcasing my academic journey, technical skills, projects, achievements, and interests. Designed with a clean, user-friendly layout, it allows visitors to explore every section effortlessly across desktop, tablet, and mobile devices.
Highlights & Features
User Experience & Design
Fully Responsive Layout: Adapts smoothly across laptops, tablets, and smartphones.
Dark & Light Mode Switcher: Lets visitors toggle themes anytime, automatically saving their preference in the browser.
Interactive Navigation Bar: Provides smooth scrolling between sections and highlights the active section as you scroll.
Portfolio Sections
Home: Features a warm welcome message, profile photo, and quick introduction.
About Me: Shares my story, core interests, hobbies, and career aspirations.
Education Timeline: Displays my academic background in an easy-to-follow timeline format.
Skills: Presents technical competencies using clean visual progress bars.
Projects: Showcases featured work with interactive View Details buttons.
Hobbies & Achievements: Highlights key accomplishments alongside personal interests outside of coding.
Contact Form: Includes real-time JavaScript validation with instant feedback messages.
